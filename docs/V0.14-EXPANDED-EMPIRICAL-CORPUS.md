# v0.14 — Expanded Empirical Corpus Assessment

## Purpose

This report consolidates a broader set of real academic artifacts used to stress-test Academic Colombia before v1.0.

The corpus intentionally includes both strong and problematic submissions. A submitted artifact is not treated as proof that every Skill should return PASS.

## Cross-case findings

### 1. Correct fact ≠ adequate academic evidence

The geopolitical paper contains selected current institutional facts that were independently confirmed against official WTO/OECD sources. The artifact still has evidence-traceability findings because many detailed paragraphs do not cite those sources inline.

This validates the separation between:
- factual verification;
- citation placement;
- source quality;
- evidence mapping.

### 2. Visual PASS ≠ academic READY

The 22-page DOCX renders cleanly, but source/evidence findings remain material.

The one-page spreadsheet DOCX also renders cleanly, while its central Excel limits are obsolete for current Excel.

Therefore:
- `academic-document-auditor` may PASS layout;
- `academic-final-review` may still return NOT READY.

### 3. Tables can be visually correct and methodologically wrong

The rice trade case includes a table that places second-semester values for 2020–2022 beside an annual 2023 value and then describes a trend.

This is a real case for:
- `academic-tables-figures`;
- `academic-critical-review`;
- `academic-evidence-mapper`.

The issue is not formatting; it is comparison-basis integrity.

### 4. Source ranking materially changes readiness

The trade-theories paper mixes books/academic sources with Scribd, Site123, Studocu and similar secondary content.

A framework that only checks whether a reference exists would miss the problem. `academic-source-evaluator` must assess authority and suitability for the claim.

### 5. Technical design requires design/runtime separation

The SENA smart-contract report defines actors, states, data fields, business rules and proposed functions. That is evidence of a design artifact, not proof that a Solidity contract was built, deployed or tested.

This validates `critical_gate` semantics against technical overclaiming.

### 6. Numbers do not automatically imply statistical analysis

Financial ratios and trade tables require quantitative checking, but do not automatically require inferential-statistics routing.

`academic-statistical-analysis` should remain conditional.

## Remaining empirical gaps

The expanded corpus does **not** justify closing the following gaps:

1. native XLSX workbook execution;
2. native PPTX editing/rendering execution;
3. actual video playback/audio/duration/access validation;
4. real statistical/correlation dataset E2E;
5. Custom GPT runtime suite;
6. Gemini Gem runtime suite.

These are coverage boundaries, not hidden failures.

## v1.0 interpretation

The corpus now supports a stronger claim:

> Academic Colombia's core academic/evidence/review architecture has been exercised across materially different real SENA and UNAD artifacts, including cases with stale facts, weak sources, citation gaps, methodological comparison errors, technical design boundaries and visually clean documents that still fail academic readiness.

It does **not** support a claim of exhaustive validation across every artifact type or platform runtime.

## Recommendation

No new general-purpose Skill is justified by this corpus.

Proceed with v1.0 release preparation after:
- release/compatibility policy;
- final repository/documentation audit;
- release notes/tag preparation.

Continue accumulating XLSX/PPTX/video/statistical/runtime cases after v1.0 or before release only when real artifacts become naturally available.
