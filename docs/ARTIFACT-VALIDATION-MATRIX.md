# Artifact Validation Matrix

## Purpose

Academic Colombia must validate not only academic prose but also the delivery artifact and any external evidence linked from it.

## Authority order

1. Activity guide.
2. Rubric/evaluation instrument.
3. Institution profile.
4. Artifact-specific validation rules.
5. APA 7 where applicable.

APA must not be forced onto artifact types where a paper-style layout is inappropriate.

## DOCX / Word

Validate:
- institutional template and page setup;
- headings, paragraphs, spacing and pagination;
- citations and references;
- captions and cross-references;
- tables and figures;
- hyperlinks;
- accessibility where feasible;
- visual rendering before delivery.

For UNAD, apply the UNAD profile unless the activity supplies another template.

## XLSX / Excel

APA does not define the whole workbook layout. Validate instead:
- workbook structure and sheet names;
- formulas and calculated values;
- visible units and labels;
- data provenance;
- source URLs or notes/comments for researched inputs;
- chart titles, axes, units and legends;
- source/attribution for charts and imported data;
- readability and formula-error scan.

When an Excel chart is inserted into a report, apply figure/table rules in the report as well.

## PPTX / Presentations

Validate:
- compliance with activity/rubric;
- slide hierarchy and legibility;
- concise citations near claims, figures or data when needed;
- final references slide when appropriate;
- attribution for images, charts and third-party visuals;
- accessible text size and contrast;
- functional hyperlinks.

Do not force paper-style paragraphs or full APA reference formatting onto every slide when it harms presentation quality. Use concise citations on slides and full references at the end unless the guide specifies otherwise.

## Video / YouTube

### External video used as a source
Validate:
- creator/channel;
- publication date;
- exact title;
- platform;
- working URL;
- relationship between cited claim and video content.

Reference pattern:
Creator or channel. (Date). *Title* [Video]. YouTube. URL

### Student-created or team-created video
If the video is the evidence itself:
- verify that the link opens;
- verify access permissions;
- verify title and authorship;
- verify duration if the activity limits it;
- include a descriptive hyperlink and/or QR only when useful;
- do not automatically treat the student's own evidence as an external scholarly source.

## Landing pages / websites created by the student or team

If the page is an evidence artifact:
- verify the public URL;
- verify responsive/usable rendering when relevant;
- verify that required sections exist;
- verify that the document clearly identifies the page as an evidence link;
- provide descriptive link text rather than raw URL only when document style permits;
- optionally add QR if useful and accepted by the activity;
- preserve a stable snapshot or screenshot when long-term availability matters.

If the landing page is cited as an informational source, treat it as a webpage and verify author/entity, date, title, site and URL.

## Infographics

Validate:
- required dimensions/file type;
- hierarchy and readability;
- factual accuracy;
- citations or source footer when third-party claims/data are used;
- attribution for external icons/images where required;
- no decorative overload;
- if embedded in Word/PDF, label as figure when appropriate;
- if the infographic itself is the main deliverable, do not force essay-style structure around it.

## Charts and graphs

Validate:
- chart type matches the analytical purpose;
- title, axes, units, scale and legend;
- data values agree with the source or calculations;
- source is traceable;
- misleading scales are avoided;
- accessibility/readability.

Preferred source note patterns:
- `Elaboración propia.`
- `Elaboración propia con datos de [Fuente].`
- `Adaptado de [Fuente].`

When the graph appears in a DOCX/PDF report, also apply figure numbering/title/note rules.

## External-link validation

For any linked evidence:
1. URL resolves.
2. Permission does not require unintended authentication.
3. Link points to the exact resource, not a homepage when avoidable.
4. Display text describes the destination.
5. The resource identity matches what the document claims.
6. A backup/snapshot is considered when the evidence may disappear.

## Critical failures

Do not mark an academic deliverable ready if:
- a required link is broken or private;
- a spreadsheet contains material formula errors;
- a Word file has unreviewed layout defects;
- a slide deck contains unreadable or uncited third-party visuals central to the argument;
- a figure/chart has unverifiable or mismatched data;
- an external artifact is claimed as evidence but cannot be accessed.
