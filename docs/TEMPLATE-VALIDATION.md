# Validación de plantillas académicas

## Alcance

Esta validación compara las plantillas y documentos de referencia suministrados con:

- APA 7 operativo del proyecto;
- perfil institucional UNAD;
- criterios generales de documentos académicos universitarios;
- jerarquía guía → rúbrica → institución → APA.

## Archivos revisados

### 1. Norma_APA_7_Edicion.pdf
Documento institucional UNAD de marzo de 2023. Se considera fuente normativa institucional de referencia para el perfil UNAD.

### 2. Plantilla_Normas_APA_7a_Edicion.docx
Plantilla institucional UNAD de 21 páginas orientada a trabajos académicos extensos y trabajos de grado.

Validación estructural:
- papel carta;
- márgenes 2,54 cm;
- Times New Roman 12;
- interlineado 2,0;
- sangría de primera línea 1,27 cm;
- numeración de páginas;
- portada institucional;
- niveles de títulos;
- tabla de contenido;
- listas de tablas, figuras y apéndices;
- secciones de resumen/abstract;
- ejemplos de tablas, figuras y referencias.

Resultado: COMPATIBLE y CANÓNICA para el perfil UNAD, con una condición: no todas sus secciones deben imponerse a actividades cortas.

### 3. Plantilla colaborativa / Plantilla_Normas_APA_7a_Edicion.docx
El contenido textual y la estructura coinciden con la plantilla institucional base. Debe tratarse como reutilización de la plantilla UNAD, no como un estándar distinto para trabajos colaborativos.

Resultado: COMPATIBLE. Las diferencias entre trabajo individual y colaborativo deben derivarse de la guía/rúbrica de la actividad, no de una regla APA separada.

### 4. Ensayo-Individual-Escenario-5-Conclusion-JHONIER-REASCO.docx
Documento de ejemplo académico, no fuente normativa.

Fortalezas:
- carta, márgenes 2,54 cm;
- Times New Roman 12;
- doble espacio;
- sangría de primera línea;
- estructura Introducción → Análisis → Conclusiones → Referencias;
- tabla integrada al argumento;
- uso de citas y referencias.

Aspectos que impiden usarlo como plantilla canónica:
- usa ampersand (`&`) en referencias/citas de dos autores, mientras el perfil UNAD en español debe aplicar la convención institucional validada;
- algunos títulos aparecen en mayúsculas sostenidas;
- la presentación de tabla combina número y título en una misma línea y debe normalizarse contra el estándar institucional;
- las referencias jurídicas deben revisarse con el workflow `LEGAL-COLOMBIA.md`;
- los metadatos y URLs deben verificarse antes de reutilizarse.

Resultado: REFERENCIA POSITIVA CON CORRECCIONES. No convertir en plantilla normativa.

### 5. Escenario4_IntroduccionCienciaPolitica_ReascoJhonier.docx
Documento de entrega que integra portada, texto, enlace/video, evidencia visual, síntesis colaborativa y referencias.

Fortalezas:
- portada compatible con UNAD;
- formato material consistente;
- buena integración de evidencia audiovisual;
- estructura proporcional al tipo de evidencia.

Aspectos que no deben generalizarse:
- título de portada en mayúsculas sostenidas;
- ampersand (`&`) en referencias;
- referencias a herramientas de IA solo deben incluirse si realmente fueron usadas/citadas y con metadatos verificables;
- descripciones entre corchetes de herramientas digitales deben seguir una plantilla validada antes de reutilizarse;
- una actividad de video no siempre necesita este mismo conjunto de secciones.

Resultado: CASO DE REFERENCIA, no plantilla normativa.

## Regla de clasificación

Los archivos académicos se clasifican como:

1. **Canonical template**: plantilla institucional oficial o validada para generación.
2. **Reference example**: documento real útil para aprender estructura, pero no para copiar reglas automáticamente.
3. **Anti-pattern example**: documento que contiene errores o convenciones que deben detectarse.

## Conclusión

Para UNAD, la plantilla institucional APA 7 debe ser la base material preferente cuando una actividad requiere documento formal y no existe una plantilla de curso más específica.

Para tareas cortas, foros, infografías, ensayos breves, entregas audiovisuales u organizadores gráficos, el sistema debe seleccionar solo los componentes necesarios y evitar importar automáticamente portada extensa, nota de aceptación, dedicatoria, agradecimientos, resumen, abstract, tabla de contenido o apéndices.
