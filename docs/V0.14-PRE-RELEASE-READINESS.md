# v0.14 Pre-release Readiness Report

## Purpose

v0.14 shifts Academic Colombia from framework construction to **evidence-based pre-release assessment**.

The objective is not to manufacture more features. It is to identify which capabilities are:
- structurally implemented;
- specified by acceptance cases;
- exercised with real anonymized academic work;
- validated in a real platform runtime.

### SENA empirical evidence added after v0.14.0

`tests/empirical/sena/EMP-SENA-2026-01-CINE-FUTURO.md` documents the real anonymized execution.

Key demonstrated behaviors:
- unsupported sector benchmarks and absolute conclusions were identified in an earlier report and removed/qualified in the corrected artifact;
- the principal financial ratios were independently recalculated from the values visible in the final report and matched normal rounding tolerance;
- an estimated collection-period figure was distinguished from a rigorously calculable exact portfolio-turnover metric;
- statistical-analysis routing was correctly treated as not applicable merely because the assignment contained numbers;
- the final DOCX rendered to nine pages without observed clipping, overlap, broken tables or missing glyphs;
- the written report, recording guide and visual presentation converged on the same bounded diagnosis;
- video acceptance remains partial because playback/audio/duration/link access were not exercised.

The earlier report is also valuable negative evidence: visual polish alone did not prevent unsupported claims. This reinforces the distinction between artifact QA and evidence/critical-review QA.

## v1.0 minimum release gates

Academic Colombia may proceed to v1.0 when all of the following are true:

1. core + Skill Contract remain stable through the final pre-release PR;
2. declarative repository validation is green on at least two normal post-introduction PRs;
3. README, Skills Directory, installation/distribution docs and license scope are consistent;
4. no unresolved critical governance or evidence-integrity issue exists;
5. empirical registry clearly distinguishes executed cases from fixtures;
6. platform runtime validation is either:
   - completed for the platform being publicly advertised as validated, or
   - explicitly marked pending/not claimed;
7. a release/compatibility policy defines what SemVer means for declarative behavior.

## What does NOT need to block v1.0

The following may continue after v1.0:
- additional SENA cases;
- more universities;
- exhaustive XLSX/PPTX/video coverage;
- more few-shot examples;
- additional external references;
- telemetry;
- RAG/runtime infrastructure;
- new platform adapters.

The stable release should describe these as coverage boundaries rather than pretending they do not exist.

## Academic integrity Skill decision

Current evidence does **not** justify a separate `academic-integrity-review` Skill before v1.0.

Existing capabilities already cover:
- source verification;
- evidence gaps;
- citation/reference integrity;
- critical review;
- AI-use policy;
- final QA.

The SENA case strengthens this decision: the current source evaluator + evidence mapper + critical review combination successfully identifies overclaiming and unsupported comparative language without requiring a new general-purpose Skill.

A dedicated Skill should be added only when real cases expose a recurring integrity gap not handled by those capabilities.

Functions intended to evade AI/plagiarism detectors remain explicitly out of scope.

## Institutional expansion decision

`institutions/TEMPLATE.md` exists so future profiles can be contributed consistently.

No new institution should be added merely to increase repository breadth before v1.0.

## Current recommendation

The framework remains in **v1.0 release preparation**, not feature development.

The SENA evidence reduces one of the largest empirical gaps identified before v1.0. Remaining release work is:
- release and compatibility policy;
- final repository/documentation audit;
- tag/release preparation;
- runtime acceptance when the actual GPT/Gem instances are available.
