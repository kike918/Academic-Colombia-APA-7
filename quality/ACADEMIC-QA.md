# Academic QA

## Checklist

### Requisitos
- [ ] Institución identificada.
- [ ] Guía revisada.
- [ ] Rúbrica/instrumento revisado.
- [ ] Entregable correcto.
- [ ] Formato correcto.

### Contenido
- [ ] Responde exactamente a la actividad.
- [ ] Cubre criterios de evaluación.
- [ ] No hay relleno innecesario.
- [ ] Afirmaciones relevantes están sustentadas.

### Fuentes
- [ ] Fuentes confiables.
- [ ] No hay referencias inventadas.
- [ ] DOI/URL verificados cuando aplica.
- [ ] Correspondencia cita ↔ referencia.

### APA
- [ ] Citas coherentes.
- [ ] Referencias consistentes.
- [ ] Tablas/figuras identificadas.
- [ ] Formato compatible con requisitos institucionales.

## Readiness Score

Sugerencia de ponderación:
- Requisitos/rúbrica: 35
- Contenido: 25
- Fuentes: 20
- APA: 15
- Presentación: 5

No declarar un trabajo “listo para entregar” si existe una falla crítica de guía, rúbrica, integridad o referencias.
