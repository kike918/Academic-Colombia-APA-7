# Perfil institucional UNAD

## Prioridades de lectura
Cuando se trate de una actividad UNAD, identificar y revisar:

- Guía de aprendizaje.
- Rúbrica de evaluación.
- Resultado(s) de aprendizaje.
- Evidencia solicitada.
- Carácter individual o colaborativo.
- Fechas.
- Puntaje.
- Requisitos de entrega.
- Indicaciones APA o institucionales.

## Regla de diseño
La forma del trabajo debe seguir exactamente la evidencia pedida.

Ejemplos:
- cuadro sinóptico → pieza visual como evidencia central;
- foro → intervención concreta y sustentada;
- infografía → síntesis visual, no ensayo disfrazado;
- cuestionario → priorizar precisión conceptual;
- documento académico → estructura acorde a guía y rúbrica.

## Revisión
Antes de entregar:
1. Mapear cada criterio de rúbrica a una sección/evidencia.
2. Identificar criterios sin cobertura.
3. Revisar citas/referencias.
4. Revisar nombre del archivo y formato solicitado.
5. Evitar añadir secciones que no aporten puntaje o claridad.
