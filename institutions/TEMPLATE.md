## Priority rules

Document only institution-specific rules supported by evidence.

Examples of categories:
- official activity guides;
- rubrics/evaluation instruments;
- institutional templates;
- citation/reference adaptations;
- artifact requirements;
- submission rules.

Do not duplicate generic APA rules unless the institution explicitly adapts them.

## Conflict resolution

Institutional rules remain below:
1. explicit user instruction;
2. current activity guide;
3. current rubric;
4. tutor/teacher instruction.

Institutional rules remain above generic APA conventions when they explicitly adapt them.

## Promotion criteria

A new institutional profile should be considered stable only when:
- primary/official sources are verified;
- authority/conflict rules are explicit;
- obsolete sources are documented when relevant;
- at least one real anonymized case has been exercised;
- no unsupported institution-specific behavior has been introduced.
