# Perfil institucional SENA

## Fuentes institucionales base

Para APA 7, usar como referencia institucional principal localizada:

- **Instructivo uso del estilo APA 7ª edición**, Sistema de Bibliotecas SENA / Dirección de Formación Profesional, 2020.
  - Copia institucional: https://revistas.sena.edu.co/index.php/Encuentro/libraryFiles/downloadPublic/72

Además, publicaciones institucionales SENA actuales continúan exigiendo APA séptima edición, entre ellas Revista RETO, Revista de Investigaciones Agroempresariales y Encuentro SENNOVA del Oriente Antioqueño.

## Advertencia de versión

Existe también un instructivo SENA de 2019 correspondiente a **APA 6ª edición**.

Regla obligatoria:
- no usar ese documento como autoridad normativa actual cuando exista la fuente APA 7;
- comprobar siempre la edición, fecha y contexto del documento institucional;
- si una guía específica del programa o evidencia entrega instrucciones distintas, esa guía tiene prioridad.

## Prioridades de lectura
Cuando se trate de una actividad SENA, identificar:

- Guía de aprendizaje.
- Competencia.
- Resultado de aprendizaje.
- Evidencia solicitada.
- Instrumento o criterios de evaluación.
- Formato de entrega.
- Requisitos institucionales.

## Regla principal
No transferir automáticamente convenciones de UNAD a SENA.

La guía o instrumento de evaluación específico tiene prioridad sobre hábitos generales de formato.

## Regla de formato
Las publicaciones SENA pueden establecer condiciones editoriales concretas —por ejemplo fuente, interlineado, número de referencias o estructura— que no deben generalizarse a todas las evidencias formativas. Aplicarlas solo cuando correspondan al contexto de la actividad o publicación.

## Revisión
1. Confirmar correspondencia entre evidencia y resultado de aprendizaje.
2. Revisar instrumento de evaluación.
3. Aplicar APA 7 cuando corresponda.
4. Verificar que el nivel de profundidad sea proporcional a la evidencia solicitada.
5. Verificar que el instructivo institucional utilizado corresponda a la edición vigente aplicable.
