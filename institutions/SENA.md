# Perfil institucional SENA

## Prioridades de lectura
Cuando se trate de una actividad SENA, identificar:

- Guía de aprendizaje.
- Competencia.
- Resultado de aprendizaje.
- Evidencia solicitada.
- Instrumento o criterios de evaluación.
- Formato de entrega.
- Requisitos institucionales.

## Regla principal
No transferir automáticamente convenciones de UNAD a SENA.

La guía o instrumento de evaluación específico tiene prioridad sobre hábitos generales de formato.

## Revisión
1. Confirmar correspondencia entre evidencia y resultado de aprendizaje.
2. Revisar instrumento de evaluación.
3. Aplicar APA 7 cuando corresponda.
4. Verificar que el nivel de profundidad sea proporcional a la evidencia solicitada.
