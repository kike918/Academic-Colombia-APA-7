## Classification

- External reference class: C — technical / open-source methodological reference.
- Repository: `K-Dense-AI/scientific-agent-skills`.
- License: MIT (verify current repository license before substantial reuse).
- Authority: methodological/technical only.
- Normative authority for APA, UNAD or SENA: none.

## Why it is useful

K-Dense provides patterns for scientific-agent workflows that can extend Academic Colombia when native skills lack sufficient coverage.

Relevant areas include:

- citation management;
- scientific critical thinking;
- scientific brainstorming;
- peer review;
- statistical analysis;
- evidence/claim validation;
- reproducibility-oriented workflows.

## Existing native mappings

Academic Colombia already contains adapted native skills influenced by these capability patterns:

- `academic-citation-manager`
- `academic-critical-review`
- `academic-statistical-analysis`
- `academic-research-ideation`
- `academic-source-evaluator`

These are native Academic Colombia implementations and must obey institutional and academic QA rules even when inspired by external patterns.

## Fallback candidates not yet fully native

Potential K-Dense reference areas for fallback include:

- claim-to-evidence mapping;
- structured peer-review checklists;
- reproducibility audits;
- advanced bibliographic deduplication;
- metadata/DOI validation workflows;
- power analysis;
- systematic literature review pipelines;
- evidence grading.

## Consumption rules

When a native Academic Colombia skill is insufficient:

1. Identify the exact missing capability.
2. Locate the narrowest relevant K-Dense skill/reference.
3. Read only the relevant workflow/reference material.
4. Check whether the method assumes scientific publication, laboratory research or another context that differs from the user's activity.
5. Adapt terminology and scope to the actual academic deliverable.
6. Reapply guide/rubric/institution/APA priority.
7. Do not copy normative claims from K-Dense into institutional profiles.
8. Record the external fallback if it materially changes the analysis.

## Example

Task: evaluate whether conclusions in an undergraduate report are supported by its tables and statistical results.

Native route:
- `academic-critical-review`
- `academic-statistical-analysis`
- `academic-tables-figures`

If these do not provide sufficiently explicit claim-to-result tracing, consult the relevant K-Dense peer-review/evidence pattern as a temporary fallback, then apply Academic Colombia QA to the adapted result.

## Promotion trigger

If a K-Dense fallback is repeatedly used, create a dedicated native skill instead of depending indefinitely on the external source.
