# academic-source-evaluator

## Descripción

Evalúa la autoridad, recuperabilidad, vigencia y uso permitido de una fuente antes de incorporarla a un trabajo académico o a las reglas de Academic Colombia.

## Entradas
- URL, documento o referencia;
- afirmación/regla que se pretende sustentar;
- institución/estilo;
- fecha de consulta.

## Flujo
1. Identificar autor/editor/entidad responsable.
2. Clasificar el origen: oficial primario, institucional universitario, publicación académica, repositorio técnico, guía secundaria, blog/producto/comunidad.
3. Verificar fecha y vigencia cuando el tema cambia con el tiempo.
4. Determinar si la fuente es recuperable por el lector.
5. Determinar si es fuente primaria de la regla o solo explicación secundaria.
6. Buscar conflicto con una fuente de mayor autoridad.
7. Evaluar si el contenido sirve para: regla normativa, ejemplo, contraste, patrón de ingeniería o simple descubrimiento.
8. Registrar incertidumbres y limitaciones.
9. Prohibir promover una fuente secundaria a autoridad primaria por conveniencia.

## Niveles sugeridos
- A: fuente primaria oficial.
- B: institución/universidad o fuente académica fuerte.
- C: repositorio técnico/metodológico con procedencia verificable.
- D: guía secundaria especializada.
- E: blog, catálogo de producto, contenido promocional o comunidad.

## Reglas críticas
- Un dominio con “apa” en el nombre no implica afiliación con APA.
- Un repositorio GitHub no es autoridad normativa aunque su ingeniería sea excelente.
- Un blog universitario puede ser pedagógicamente útil sin ser política institucional.
- Para reglas cambiantes (IA, software, legislación) comprobar actualidad.

## Salida
- nivel de autoridad;
- vigencia;
- recuperabilidad;
- uso recomendado;
- conflictos;
- decisión: incorporar / usar solo como ejemplo / descartar / verificar más.
